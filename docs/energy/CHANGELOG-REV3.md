## Contrôle des suppressions

Le contenu intégral des quatre documents Markdown REV2 est **inclus textuellement** au début des versions REV3 associées (référentiel, matrice, roadmap et Codex). Le CSV REV3 contient **toutes** les lignes REV2, puis les nouvelles décisions. Les cinq sources REV2 originales sont aussi incluses dans `references/rev2-source/` pour audit, **mais ne seront pas installées par défaut dans Git**.

En cas de publication antérieure REV2 sur la branche Energy, conserver ces fichiers comme historique ; ne pas les réécrire ni les effacer. Le point de reprise est `INDEX-ACTIF-REV3.md`.
